# uat026-w5e0z

A basic example of how to use the uat026-w5e0z package.

## Installation

In the event `uat026-w5e0z` is not published to npm, you can install it locally by running the following command in the examples folder:

```sh
npm run setup
```

This will rebuild the parent package and install it locally.

Otherwise you can install it from npm:

```sh
npm install uat026-w5e0z
```

## Usage

To run the example, run the following command in the examples folder:

```sh
npm run start
```
